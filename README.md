# Pi Dalil (دليل باي)

AI shopping agent for Pi Network: finds products and services in stores that officially accept Pi, scores every store with a transparent trust formula, shows store and product ratings, fills the shipping details and sends the buyer straight to the store's own Pi checkout.

- Design: [`docs/PI_DALIL_DESIGN.md`](docs/PI_DALIL_DESIGN.md)
- Plan, research, costs and pricing: [`docs/PI_DALIL_PLAN.md`](docs/PI_DALIL_PLAN.md)

The code base is forked from [Dalil (PayPal AI)](https://github.com/medomohamed22/PayPal_Ai) at commit `904d3d6` and is being migrated from PayPal to Pi (see the plan, section 5).
